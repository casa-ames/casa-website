# Supporter logo sources

These files are official artwork published by the City of Ames. Keep the source files here for future print or higher-resolution uses; the optimized website versions live in `public/images/supporters/`.

- `city-of-ames-official.svg` — the SVG used in the header of the [City of Ames website](https://www.cityofames.org/).
- `cota-black-official.ai` — the official black Commission on the Arts Illustrator artwork, downloaded from the City’s [Citing COTA Funding resources](https://www.cityofames.org/My-Government/Departments/City-Managers-Office/Commission-on-the-Arts). The file is PDF-compatible vector artwork.
- `cota-color-official.eps` — the official color Commission on the Arts EPS from the same City resource page.

The site displays the City SVG directly and a small WebP rendition of the official black COTA vector. Confirm the current grant-year acknowledgment and artwork rules with the Commission on the Arts before final publication.
